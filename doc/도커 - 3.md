# 1. Dockerfile의 본질

> Dockerfile = **이미지를 레이어(layer)로 쌓는 과정**

각 줄이 하나의 레이어가 됩니다.

```dockerfile
FROM node:18
WORKDIR /app
COPY . .
RUN npm install
CMD ["npm", "start"]
```

👉 이 5줄 = **5개의 레이어**

---

# 2. 레이어 구조 이해 (핵심)

Docker 이미지는 이렇게 쌓입니다:

```plaintext
node:18
  ├─ WORKDIR /app
  ├─ COPY . .
  ├─ RUN npm install
  └─ CMD npm start
```

### 특징

* 각 레이어는 **캐시됨**
* 변경이 생기면 **그 레이어부터 다시 빌드**

---

# 3. 캐싱 동작 원리 (진짜 중요)

Docker는 빌드할 때:

> “이 명령 이전에 동일한 상태였나?”를 보고 캐시 사용

---

## ❌ 잘못된 Dockerfile (매번 npm install 실행됨)

```dockerfile
COPY . .
RUN npm install
```

👉 코드 하나만 바뀌어도
→ COPY가 변경됨
→ npm install 다시 실행 😡

---

## ✅ 올바른 구조 (캐싱 최적화)

```dockerfile
COPY package.json package-lock.json ./
RUN npm install

COPY . .
```

👉 package.json 안 바뀌면
→ npm install 캐시 사용 🚀

---

# 4. 최적화 핵심 전략 3가지

## 1) “변경 적은 것 → 먼저”

* package.json
* lock 파일

## 2) “변경 많은 것 → 나중”

* 소스 코드

## 3) 의존성 설치는 분리

---

# 5. 실전 Dockerfile (Node / Next / Nest 공통)

```dockerfile
# 1. 베이스 이미지
FROM node:18-alpine

# 2. 작업 디렉토리
WORKDIR /app

# 3. 의존성 먼저 복사 (캐싱 포인트)
COPY package.json package-lock.json ./

# 4. 의존성 설치
RUN npm install

# 5. 나머지 소스 복사
COPY . .

# 6. 빌드 (Next / Nest 등)
RUN npm run build

# 7. 실행
CMD ["npm", "run", "start"]
```

# 6. .dockerignore (이거 안 쓰면 망함)

```plaintext
node_modules
.git
.env
dist
```

👉 이유:

* 불필요한 파일 복사 방지
* 빌드 속도 ↑
* 이미지 크기 ↓

---

# 7. 멀티 스테이지 빌드 (실무 핵심)

이미지 사이즈 줄이는 핵심 기술

## ❌ 문제

* build tool까지 다 포함됨 → 이미지 무거움

---

## ✅ 해결 (멀티 스테이지)

```dockerfile
# 1단계: 빌드
FROM node:18 AS builder

WORKDIR /app
COPY . .
RUN npm install
RUN npm run build

# 2단계: 실행용 (가벼움)
FROM node:18-alpine

WORKDIR /app
COPY --from=builder /app/dist ./dist
COPY package.json ./

RUN npm install --production

CMD ["node", "dist/main.js"]
```

---

### 효과

* 이미지 용량 ↓↓↓
* 보안 ↑
* 배포 속도 ↑

# 8. 레이어 최적화 팁

## 1) RUN 합치기

```dockerfile
RUN apt-get update && apt-get install -y curl
```

👉 레이어 줄이기

---

## 2) 불필요 파일 제거

```dockerfile
RUN npm install && npm cache clean --force
```

---

## 3) alpine 사용

```dockerfile
FROM node:18-alpine
```

👉 기본 이미지 작음

# 9. 자주 하는 실수

## ❌ COPY . . 먼저

→ 캐시 다 깨짐

## ❌ node_modules 포함

→ 이미지 터짐

## ❌ devDependencies 포함

→ 쓸데없이 무거움

```bash
npm install --production
```
